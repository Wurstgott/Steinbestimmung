# Steinbestimmung

Von Carlo Maximilian Engeländer.

Eine kleine, verspielte Web-App zu 25 Edel- und Schmucksteinen: jeder Stein als echtes Foto in zwei Ansichten (Natur und geschliffen), mit Leitwort, Bedeutung und einem Quiz.

- **Blankreiben:** In der Detailansicht mit dem Finger über den Rohstein reiben, bis der geschliffene Stein erscheint.
- **Eselsbrücke:** Zu jedem Stein eine Rätselkarte zum Umdrehen, die sich mit einem Foto auflöst.
- **Woher der Name kommt** und **Sage und Geschichte** zu jedem Stein, auf Wunsch vorgelesen.
- **Zieh einen Stein**, Filter nach Stimmung und Merkliste (bleibt nur im eigenen Browser gespeichert).
- **Quiz:** Erkennst du den Stein am Foto? Das Eselsbrücken-Bild gibt es als Tipp.

Reines HTML, CSS und JavaScript ohne Build-Schritt. Läuft über GitHub Pages (Branch `main`, Ordner `/`).

Fotos: Wikimedia Commons, siehe [BILDNACHWEISE.md](BILDNACHWEISE.md). Schriften: Bodoni Moda und Instrument Sans (SIL Open Font License).

Die Bedeutungen der Steine sind überlieferte Zuschreibungen und kein Ersatz für ärztlichen Rat.
